# Final report (LaTeX)

The report uses the course IEEE conference template (`IEEEtran.cls`). The page limit is 8 pages, not counting references and the appendix.

## Build

From this folder:

```bash
latexmk -pdf main.tex
```

Without latexmk, run `pdflatex main`, `bibtex main`, `pdflatex main`, `pdflatex main`. Overleaf also works: upload the whole `report/` folder and set `main.tex` as the main file.

Build output (`*.aux`, `*.log`, `main.pdf` and so on) is not committed.

## Layout

| Path | Content | Owner |
|---|---|---|
| `main.tex` | Title, authors, abstract, section order | all |
| `sections/01_introduction.tex` | Task, motivation, research questions | all |
| `sections/02_data.tex` | Data description and EDA | D |
| `sections/03_preprocessing.tex` | Feature handling table, cleaning, joins | A and D |
| `sections/04_methods.tex` | Validation, metrics, feature groups, trend handling, models, tuning | A |
| `sections/05_evaluation.tex` | Results table, ablations | B and C |
| `sections/06_error_analysis.tex` | Noise floor, residuals, importance | D |
| `sections/07_limitations.tex` | Limitations and future work | all |
| `sections/appendix.tex` | Workload table, hyperparameters | all |
| `references.bib` | BibTeX entries | all |
| `tables/`, `figures/` | Generated by scripts. Do not edit by hand. | |

`\todo{...}` prints red text. Search for it to find open work, and remove all of them before submission.

## Generated tables and figures

`python -m scripts.trend_analysis` (from the project root) rebuilds `tables/trend.tex`, `tables/split.tex`, `figures/rent_index.pdf` and `figures/monthly_rmse.pdf` from `results/results.csv`. Rerun it after new experiments are logged.
